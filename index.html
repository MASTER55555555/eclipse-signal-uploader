Eclipse Signal Uploader

Eclipse Signal Uploader is a personal, single-user tool built and operated by Onurhan Demir. It publishes videos produced by an automated astronomy content pipeline to YouTube channels owned by the same Google account.

The tool uses YouTube API Services (YouTube Data API v3) to upload videos, set their titles, descriptions, tags and privacy status, and read back the resulting video details. It is not distributed to, installed by, or used on behalf of any other person or organization.
